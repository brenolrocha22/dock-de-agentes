# Dock de Agentes

Protótipo React + TypeScript + Vite para explorar um dock de agentes local. A interface é demonstrativa: nenhuma tarefa é enviada a serviços externos.

## Requisitos

- Node.js 22.6 ou superior
- npm

## Executar

```powershell
npm.cmd install
npm.cmd run dev
```

## Verificar

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

O dock expande com hover ou foco de teclado. Selecione Code, Research, Writer ou Tasks para abrir o painel e executar uma tarefa simulada.
